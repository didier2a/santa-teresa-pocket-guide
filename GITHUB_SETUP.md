# Mise en ligne sur GitHub Pages

Dépôt : `santa-teresa-pocket-guide` (public).

1. Le contenu de l'application doit rester à la racine du dépôt.
2. Dans **Settings > Pages**, choisir **Source: GitHub Actions** si nécessaire.
3. Le workflow `.github/workflows/pages.yml` publie le site après chaque push sur `main`.
4. URL attendue : `https://didier2a.github.io/santa-teresa-pocket-guide/`.
5. Sur le Galaxy S22, ouvrir cette URL dans Chrome puis choisir **Installer l'application** ou **Ajouter à l'écran d'accueil**.

Le projet utilise des chemins relatifs afin de fonctionner correctement sous le sous-chemin GitHub Pages du dépôt.
