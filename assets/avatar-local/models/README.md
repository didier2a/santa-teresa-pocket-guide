# Claire — avatar 3D temporaire

`claire-rocketbox.glb` provient du modèle `Female_Adult_17_facial` de la bibliothèque Microsoft Rocketbox.

- Source : https://github.com/microsoft/Microsoft-Rocketbox
- Licence : MIT, copyright (c) 2020 Microsoft
- Usage : validation temporaire de TalkingHead 1.7 et HeadAudio 0.1 dans Pocket Guide
- Format : glTF 2.0 binaire, textures WebP et compression Meshopt
- Taille : 975 504 octets
- Empreinte SHA-256 : `a869cc38a324e6fdec6b089bd47e60bee3112065c69e715190cd820c14c64539`

Le modèle a reçu des noms d’os compatibles Mixamo, les 15 visèmes Oculus et les 52 blendshapes ARKit. Il reste un modèle temporaire : il ne représente pas l’identité visuelle définitive de Pocket Guide.

La conversion reproductible des noms et matériaux se trouve dans `scripts/avatar/prepare-rocketbox-claire.mjs`.
